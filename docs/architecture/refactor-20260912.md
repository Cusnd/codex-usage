## CUA 页面验收

使用 CUA 操作本地构建、Vite 展示构建和隔离 Wrangler / Workerd / D1，未使用 Playwright。测试地址为本机回环，未读取个人日志或接入真实账户。云端通过本地专用 `cloud/test/browser-worker.ts` 建立合成会话，其后调用真实 Worker 路由；该入口不进入生产包。

- 本地：自定义时间范围显示 119.21M Token、28 Sessions、92 Turns；项目选择显示 48.6M；打开任务与轮次后，Agent 自身 18.2M、后代 30.4M、团队 48.6M。设置保存显示成功，总览出现订阅参考及缺失档位标记，Token 总量保持一致。
- 展示入口：同一套总览显示 119.21M / 28 / 92，参考时钟固定为 2026-09-08；设置保留独立值；启动项显示“本地应用专属”。
- 云端：未上报设备时显示 3.1.2 门禁；真实 v3 摄取返回 `applied`，随后自动解锁并显示 72K / 1 / 1；浏览器显示完整历史缓存就绪。总览、任务、轮次、Agent 和设备/项目设置区可打开。新合成用户重新进入门禁，旧任务数据未显示；再同步后出现该用户的完整任务数据。
- 布局：检查本地桌面总览及云端 390×844 视口，云端导航、筛选、同步状态和表格容器保留窄屏布局；这不是实体手机、触屏或弱网验收。
- 最终已加载页面的浏览器错误日志未见错误。原版本门禁夹具只有 Token 记录，最初缺少 Agent 查询所需的会话记录；本次补入真实投影的 session_meta，并把固定合成设备凭据改为逐次随机值以支持多用户重复验收，随后复验通过。这些调整仅在本地验收夹具。

页面 AX 与截图位于 [browser 证据目录](../../artifacts/refactor-implementation-20260912/browser/)。未重新验证真实 GitHub OAuth、真实云端账户或离线浏览器的全部操作组合；自动测试覆盖相关缓存、读取和同步契约。
