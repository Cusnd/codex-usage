## 实施中明确的修正

1. `origin_device_id` 与上传者分开；无法证明过去的执行机器时保留未知。完整记录链覆盖所有完整原始行，但只保留链摘要及白名单投影，不持久保存聊天正文。
2. 分支 remote 与 `origin` 的仓库身份冲突不能自动归并；来源项目身份包含根目录，避免多个 worktree 路径被同一 common directory 掩盖。
3. 旧父任务“已出现”不代表其覆盖完整；父记录仍在导入时，不将未匹配的继承前缀直接判作新消耗。
4. Linux 实跑发现并修复 RPC 子孙进程组清理、systemd 特殊字符参数和缺少用户管理器的启动分支。实际临时 unit 已清理。
5. 任意大数查询已接入安全范围证明与分批 BigInt 回退，精度边界测试通过；不得以外层 `CAST(SUM(...) AS TEXT)` 宣称溢出中间结果已经精确。超大偏移的精确回退会增加重复扫描成本，仍需真实 D1 性能验收。
