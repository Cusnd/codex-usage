# 样式升级

视觉方向参考 [concept.png](concept.png)：白色内容区、浅色侧栏、深色当前导航、青绿色选中状态。实现继续使用真实 API 数据。

## 统一规则

- 页面布局：232px 桌面侧栏、28px 主内容间距；窄窗口缩为带文字的图标导航。
- 字体：本地打包的 Inter Variable；中文回退到系统 UI 字体。标题、指标、表头和说明分别有明确层级。
- 指标：合并为连续统计条，用分隔线代替独立卡片之间的大段留白。
- 表格：统一表头、行距、数字右对齐、分组切换和分页样式。
- 控件：40px 常规选择器；页面内菜单沿用已验证的搜索、键盘和点击逻辑。
- 图标：Lucide SVG 统一导航、刷新、分页、返回和下拉标识；不使用文本字符承担箭头。

## 视觉与交互核对

已使用 Codex App 内置浏览器核对 1440×1100 桌面和 520×1000 窄侧栏，打开设计稿及实际截图比较：

1. 浅色导航、深色选中行与布局层级一致。
2. 指标合并、字号层级和数字对齐一致。
3. 白色面板、青绿色强调与边界颜色一致。
4. 筛选栏、分组按钮、表格和趋势图的顺序一致。
5. 图标均使用 SVG；各选择器箭头与按钮的垂直中心差为 0px。
6. 窄窗口菜单按 clientWidth 避让滚动条；测量右侧保留 12px，不再贴边裁切。
7. 选择器展开、Escape、导航和设置菜单可以操作，控制台无 error/warn。

保留的差异：实际数值和曲线来自 API；指标仍提供简短口径说明；对比区保留可分页的分组明细，而非将设计稿里的示意增长数字写死。
