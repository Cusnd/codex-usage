# ATLAS 前端视觉重构验收

日期：2026-09-08。保留总览、消耗分析、任务明细、设置及分析页目录／明细结构，重新统一排版、颜色、控件、图表和状态表达。验收对象为生产构建在真实可见浏览器中的界面；截图来自隔离示例服务，不含个人生产数据。

## 设计与结构

- 冷中性底色 `#F5F6F8`、白色表面、正文 `#202531`、次级文字 `#667085`、分隔线 `#E2E5EB`、强调色 `#354FC4`。输入、缓存读取、输出使用跨页面一致的颜色；状态色独立。
- 本地 Inter 数值、系统中文字体、等宽标识符；标题约 26px、主要数值 36px、正文 14px。通过对齐、间距和分隔组织数据，减少卡片边框及粗体的竞争。
- 共享筛选、时间选择、搜索、表格、提示框及表单样式。账户来源与状态独立呈现；团队明细区分当前 agent、后代合计与团队合计。
- 删除整页入场效果，保留短时操作反馈，并遵守减少动态效果设置。表格滚动区域可聚焦，时间浮层支持 Escape 关闭并返回焦点。
- `App.tsx` 保留外壳与数据协调，总览、设置、账户状态拆为独立组件；`Atlas.tsx` 拆出趋势、目录、任务／轮次和共享辅助组件。
- 删除旧 `style.css` 与 `atlas.css`，改为 `styles/` 下的设计变量、基础、组件、布局、分析、设置、响应式样式。未追加新的全局覆盖层。
- 公共 API、后端、共享数据类型及 URL 参数语义未调整；未新增运行时依赖。

## 本地复现

在仓库根目录执行 PowerShell：

```powershell
npm run build
$env:CODEX_USAGE_PREVIEW_PORT = '8876'
$env:CODEX_USAGE_PREVIEW_ACCOUNT = '1'
npx tsx scripts/design-preview.ts
```

打开 [固定日期总览](http://127.0.0.1:8876/?range=custom&from=2026-09-02T04%3A00%3A00Z&to=2026-09-09T04%3A00%3A00Z)，显示时区使用 America/New_York。省略 `CODEX_USAGE_PREVIEW_ACCOUNT` 时仍使用原有空账户示例状态。该服务使用合成数据，不读取真实账户额度；截图是在成本关闭时生成。
