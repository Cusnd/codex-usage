# 用量图录：交互与动效

## 设计依据

本次延续现有矿物白、墨黑、群青、Inter 数字和细分隔线的视觉系统。目标是帮助用户识别当前位置、理解局部变化、保留数据比较的视觉参照。用户明确要求避免模板化动效，并让动画与组件功能、人体工学及全局风格一致。

## 动效与功能对应

| 操作 | 反馈 | 设计原因 |
| --- | --- | --- |
| 切换主导航或分析维度 | 同一条群青下划线在 260ms 内移动至新入口；跟随真实文本宽度 | 连续表达位置变化，沿用原有选中标记 |
| 切换页面 | 180ms 透明度过渡，不改变布局位置 | 轻量提示上下文改变；内容和操作无需等待动画结束 |
| 选择项目、模型或任务 | 详情区域 6px 横向归位，240ms；Session 信息取得后呈现 | 对应目录到详情的浏览关系，保持图表和目录稳定 |
| 展开轮次 | 原箭头转动 90°；局部内容 3px / 220ms 呈现 | 箭头表达开合状态，内容紧随当前行；按钮和焦点不被替换 |
| 打开菜单 | 200ms，围绕靠近触发器的边缘展开 | 向上弹出与向下弹出使用不同原点；Escape 沿用原有焦点恢复 |
| 按钮、表格行和链接 | 160ms 状态颜色；方向图标最多位移 2–3px | 反馈可操作性，保持文字和点击区域不移动 |
| 等待请求、刷新来源 | 小点明暗或刷新图标旋转，周期 1400ms | 动态只对应真实运行状态；静止时不持续吸引注意 |

快速连续操作时取消旧的页面动画；导航过渡从当前呈现位置继续。使用统一的快速减速曲线，无弹簧回弹。没有引入动画依赖。

## 阅读和可访问性

- 列表不逐行错峰浮入，图表不扫入，数字不滚动计数，数值始终准确。
- 页面动效由 pathname 驱动，目录动效由选择身份驱动；普通筛选、分页和后台轮询不重播整页动效。
- 不为了动画重新挂载页面；展开轮次保留按钮及 SVG，菜单沿用键盘操作。
- CSS 和 Web Animations API 均尊重 `prefers-reduced-motion`，运行期间更改偏好会取消当前 JS 动画。状态标记和内容仍立即可见。
- 悬停方向提示仅用于支持 hover 的精细指针。
- 本次为内容呈现与状态过渡；没有为趋势区域和表格行实现退出高度动画。

## 验证

在项目自带的隔离示例数据服务上验证，未使用示例数据替换真实记录。

- 最终 `npm run build` 通过；现有 41 项 `npm test` 全部通过。
- 1440px 桌面和 390px 窄屏：导航规则的位置、宽度与选中控件一致；窄屏无页面横向溢出。
- 轮次展开：SVG 身份保留、按钮焦点保留、无整页动画调用。
- 菜单：动效存在，Escape 恢复触发按钮焦点。
- 快速切换维度：最终选中位置正确。
- 减少动态效果：无 JS 动画调用、无运行中的动画、菜单动画为 none、导航 transition 为 0s。
- 浏览器控制台 0 errors / 0 warnings。
- Vite 保留已有的 >500kB 包体积提示；本次未改动打包策略。
