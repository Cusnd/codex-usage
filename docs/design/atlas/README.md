## 视觉系统

- 背景 `#f6f6f2`，主要文字 `#171a24`，群青 `#2944be`，分隔线 `#dfe1e4`。选中项同时使用背景、边线或下划线，不只依赖颜色。
- 数字使用本地 Inter Variable 和等宽数字特性；中文使用系统中文 UI 字体。显示标题、数值、表头和辅助信息分级。
- 顶部水平导航；主要内容在同一平面，采用分隔线与留白，不使用嵌套卡片。目录默认 320px，右侧明细占剩余宽度。
- 总览延续同一配色、统计分项和分隔线；账户统计始终有独立来源说明。设置使用按行组织的表单，价格按模型分组，长上下文价格折叠。
- 900px 以下，目录与明细分开显示；返回目录保留 URL 中的上下文。窄表隐藏部分独立列，用展开区域提供全部细分。趋势可收起。

## 交互与统计范围

上方摘要和趋势始终响应全局筛选；选中项目或 Session 只改变右侧明细。切换分析入口保留时间与筛选，重置旧选择和对应分页。搜索属于当前列表，不把列表搜索当成全局统计条件。

日期柱支持点击下钻；日期选择器提供键盘替代入口。范围拖选释放时提交查询；原范围保存到 URL，可以恢复。日界线按 IANA 时区处理，使用包含起点、不包含终点的区间。

任务标题来自本机 `session_index.jsonl` 的元数据；无标题时显示项目名与短 ID。全局轮次按 Session ID 和 Turn ID 联合区分。身份缺失记录按 Session 单列，不冒充一个已识别轮次。

## Token 与参考成本

- 默认展示非缓存输入、缓存读取、输出和缓存读取占比。
- 非缓存输入为输入减去缓存读取，包含缓存写入。普通输入进一步减去已知写入量；写入未提供时普通输入不强行推算。
- 在设置启用成本后显示缓存写入和 USD 参考额。写入缺失显示未提供；部分缺失显示部分小计。
- 参考价核对日期：2026-09-08。预置 Astra、Sol、Terra、Luna 的 Standard API 短／长上下文单价，允许逐模型覆盖或增加精确模型 ID。
- [官方定价](https://developers.openai.com/api/docs/pricing)及[缓存计费口径](https://developers.openai.com/api/docs/guides/prompt-caching)。价格按百万 Token；写入属于输入细分，不能把普通输入价和完整写入价重复相加。
- 估算使用整数精度计算后返回十进制金额。按记录判断长上下文档位，然后跨模型、轮次和任务汇总；不按 Session 累计输入判断单请求档位。
- 未知模型不套用其他模型价格。缺失用量／单价、旧格式档位不确定等情况标记为不完整估算；缺失写入时已知参考额不含未知写入差价。
- 此功能不代表订阅账单，不包含工具费用、Fast/Batch/Flex、区域附加费或历史时点价格重放。覆盖单价会重新估算历史记录。

```powershell
npm run build

```

验证页监听 `127.0.0.1:8766`，使用内存数据库和空数据源目录，不读取真实账户或会话。首次启动自动断言：总量 119.21M、28 个 Session、92 个 Turn，选中 Session 输入 17.80M、输出 400K，总量 18.20M；每日合计为 8.20、12.50、18.40、31.40、16.20、14.01、18.50M。

浏览器打开脚本输出的固定范围 URL。真实应用继续使用 `127.0.0.1:8765` 和自己的统计数据库。

## 图像生成提示词摘要

使用内置 ImageGen；参考已选定的 Session 修订图。共用提示词要求矿物白、墨黑、群青、水平导航、细分隔线、目录与明细布局、可阅读中文、局部统计范围、日／小时趋势，以及明确的示例数据标识；禁止装饰性卡片墙、渐变、伪造生产力指标及订阅费用换算。

四个提示词分别聚焦项目目录、Session 的多模型轮次、09-05 单日小时趋势、跨任务 Turn 与展开细分。最终可计算截图补充用户随后要求的缓存分项及可选参考成本，不沿用生成图的错误数值。
