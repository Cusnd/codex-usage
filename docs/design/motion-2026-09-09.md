# ATLAS 交互动效：实现与验收

日期：2026-09-09。依据本轮已批准的交互动效方案实现；当前规范以本文为准，09-08 文档保留为历史记录。

## 设计语言

沿用冷灰背景、白色表面、群青强调色和准确直出的数字。时间与粒度使用同一个白色选中块，主导航和分析维度使用群青下划线。浮层从触发器边缘出现；折叠释放自身空间；层级进入与返回具有方向。主导航页面本身直接切换。

| 动效 | 时长 | 方式 |
| --- | --- | --- |
| 按下 / 悬停 | 80 / 140ms | 表面内阴影和颜色，点击区域原位 |
| 局部结果、图标 | 160ms | 透明度 |
| 浮层进入 / 退出 | 200 / 140ms | 透明度和最多 6px 位移；向上弹出反向 |
| 小型折叠、开关、时区区域 | 220ms | 高度、滑块位置 |
| 范围标记、普通面板、趋势布局 | 260ms | 位移、宽度、高度 |
| 层级进入 / 返回 | 240ms | 桌面 8px，900px 及以下 16px，反向返回 |
| 可比较图形 | 320ms | Recharts 插值，ease-out |

位置及展开使用 `cubic-bezier(0.22, 1, 0.36, 1)`；浮层退出使用 `cubic-bezier(0.4, 0, 1, 1)`。无启动延迟。减少动态效果偏好启用时，取消 CSS 动画和过渡、结束运行中的 WAAPI 动画，并关闭图形插值。

## 状态与生命周期

- `motion-state.ts` 记录查询操作和按来源手动刷新身份。每个结果只消费一次；相同载荷和后台轮询不重复播放。缓存结果的时间戳可以早于点击，仍按本次用户选择处理。
- `motion-data.ts` 从查询结果派生动画状态，不改公共 API、URL 契约或设置持久化结构。新查询使用同路由旧结果占位时明确显示更新中；错误消费操作身份，避免后续轮询误播。
- `animateMotion` 每个元素最多一个受管动画。新动作取消旧动作，旧完成回调无法清除新动画；组件卸载清理受管动画。
- 折叠从当前可见高度反向，内容异步改变高度时重新测量内层，窗口变化结束临时动画。关闭立即 inert / aria-hidden，退出中的表单 fieldset disabled。
- Recharts 实际图形通过 portal 渲染；淡入定位到真实 `.recharts-area` / `.recharts-bar` 图层，坐标轴和工具栏不参与淡入。
- 没有增加动画依赖。Vite 开发代理同时修正为 `^/api(?:/|$)`，防止 `/api.ts` 前端模块被误代理；示例模式不连接本地 API。

## 自定义收起闪烁回归

用户报告“从自定义切换回其他按钮时，界面会闪烁一下”。在 390px 宽度，用 CUA 浏览器中逐帧 DOM 几何采样复现。

**原因**：WAAPI 完成后同步释放 `fill`，React 的退出卸载发生在下一次提交；中间一帧重新呈现了表单自然高度，导致下方内容回跳。

| 采样 | 退出末段高度（px） | 回弹 |
| --- | --- | --- |
| 修复前 | `0.039 → 0.008 → 0 → 233 → 0` | 1 次，下方趋势同步回跳 233px |
| 修复后 | `0.039 → 0.008 → 0` | 0 次，无退出节点残留 |

修复在共用 `usePresence`：关闭完成时同步保留 `height: 0`（非 popup）和 `opacity: 0`，直到 React 卸载；再次打开完成后释放临时样式。这同时覆盖自定义、轮次详情及共用折叠。

## 后续体验修正：统计切换与图表提示

用户进一步反馈，切换时间口径时文字和统计区域闪烁、图表提示浮窗没有可见动画。本次调整覆盖以下行为，并优先于上表中的摘要淡入描述：

- 总览统计摘要关闭整体淡入，读数直接更新，更新中状态仍保留。浏览器逐帧采样统计容器透明度始终为 1。
- 已有数据的不可比较图形切换，透明度由 0.7 恢复到 1，不再从完全透明开始；首次图形仍可淡入。实际范围切换采样的图形最低透明度为 0.7。
- Recharts 会先挂载隐藏的 Tooltip 来测量尺寸，原先内容挂载即播放的 CSS 动画可能在显示前结束。现将启动条件改成 Tooltip wrapper 实际 `visibility: visible`，总览和分析页共用 160ms 淡入。
- 悬停验收捕获 `atlas-tooltip-enter`，触发时 wrapper 为 visible、时长 0.16s；沿曲线移动到下一数据点，事件计数保持 1，内容准确更新，位置 transition 为 0s。

## 后续体验修正：卡片位移与曲线连续变形

用户进一步明确要求卡片在不同数据点间平滑移动，以及切换曲线时连续变形。本节覆盖此前“Tooltip 位置即时跳转、时间桶或坐标域变化仅淡入”的规则。

- 总览与分析页 Tooltip 采用 180ms ease-out 位置过渡；内容保持最新实际读数，首次显示保留 160ms 淡入。快速换点由 CSS 从当前显示位置接管，不排队。
- 面积曲线在同来源、时区和单位下，用户切换日期范围或日/小时粒度均采用 297ms smoothstep（t²(3−2t)）几何插值，起步和收尾慢、中段快。使用下述完整曲线采样和运行中形状快照；中间形状仅为视觉过渡，不作为统计数据或 Tooltip 读数。
- 数据来源变化、非有限值、空数据仍使用状态切换；后台变化不播放，减少动态效果偏好下直接完成。柱状图保留原有可比较条件。
- CUA 合成数据验收：日切小时记录 53 个不同中间曲线路径，图形透明度全程为 1；Tooltip 跨点记录 22 个不同位移矩阵，实际 transition 为 `transform 0.18s ease-out`。

随后针对“小时 → 日不够平滑”的反馈，替换了 Recharts 默认的比例索引匹配：默认会在多点变少点时先丢弃旧点，使动画首帧失去原峰谷。现使用完整旧点集合、单调 Hermite 曲线及共享采样位置插值，包含原曲线节点，首尾返回准确原始形状；中断时复用当前显示形状。真实浏览器反向切换的首个变动帧，在 33 个横向采样位置的最大位移约 0.07px。回归测试验证多峰旧曲线在进度 0、0.001、0.5 和 1 时保持连续及准确终点。

### 首次切换跳变与反向闪烁

- 首次布局经过图例尺寸调整后，Recharts 在未播放动画的坐标更新中可能保留过期起点。面积图适配器现在自行保存最新显示几何；回归测试覆盖初始布局调整、过期快照与中途反向。
- 等待首次新查询时，已有曲线曾误触发入场淡入。CUA 捕获透明度 `1 → 0 → 0.216695 → 1`。面积图取消首次淡入，等待新结果时继续当前动画，动画回调保持稳定。
- 修复后冷启动按小时、300ms 后切回按日，CUA 采样记录 76 次路径变化，曲线缺失帧为 0，透明度始终为 1，结束后恢复准确每日路径且运行标记清除。
- 非线性节奏使用显式 smoothstep 函数，避开当前安装的 Recharts 对 `ease-out` / `ease-in-out` 名称的反向映射。按用户要求提速 75%，持续 297ms（520 / 1.75），首尾速度为零，中段最快，无过冲。
- 本轮验证：7 项动画回归测试、类型检查与生产构建通过。预览仍为合成数据，未发布本轮变更。

### 首次两次卡顿：查询结果与动画生命周期分离

进一步用 CUA 对照开发模式和生产构建，发现卡顿并非主要来自 SQL 查询：生产基线趋势查询为 8–10.2ms，但切回已缓存的日数据后，刷新返回相同内容，将 `animate` 设为 false，使正在播放的动画直接结束，仅留下 2 种曲线形状。另一次中途刷新在保持动画开关后仍因图表重绘重复启动，播放区间被拉长至约 606ms。

修复：

- 曲线预处理只在目标几何变化时执行一次，缓存排序后的端点、斜率、共享采样和坐标差值；每帧只计算插值，取消每帧 JSON 序列化、排序和曲线重采样。
- 动画意图与目标数据绑定，相同内容的刷新、pending 及查询时间戳更新不改变当前播放意图；真正不同的后台数据仍直接更新。
- 将使用 Workspace 的包装组件与 memo 化的图表绘制组件分开，实际 rows、粒度、时区不变时，刷新状态不再进入 Recharts。数据签名只随实际数据引用变化重新计算。
- 趋势保留最后成功数据及其粒度；慢请求期间维持旧图，失败后显示错误并保留旧图，合法空结果仍显示空状态。切换后的旧请求不会覆盖最新选择。
