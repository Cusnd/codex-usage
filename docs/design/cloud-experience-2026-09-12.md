## 已实施的优化

1. **首屏少一个串行往返。** `/api/v3/me?bootstrap=1` 在同一次已认证响应中返回用户和兼容状态。普通 `/me` 合同保持兼容，旧服务端没有 bootstrap 时回退到独立兼容查询；仍有周期和焦点复核。
2. **弱网不会使已核对的页面消失。** 当前会话已验证后，传输错误、408 / 429 / 5xx 保留页面并提示；401 / 403、明确协议不匹配和未知错误关闭许可。旧请求不能覆盖较新的拒绝结果，许可不跨用户或新文档持久化。
3. **云端统计先展示，离线实体在后台下载。** 完全冷缓存取得经验证并持久化的 baseline read 后即可查询固定 cut 的服务端统计。有完整旧视图时继续使用旧视图，直到新视图原子提升；不提前标记缓存完成或增加 applied 计数。
4. **合并重复请求并自动恢复过期读取。** 同凭证 renew 和相同 GET 合并，调用者可独立取消；`BASELINE_REQUIRED` 进行有界共享恢复。cut 变化使整页捕获视图失效，避免混用；删除后的晚到响应不能复活查询缓存。
5. **减少完整下行的往返。** manifest 每页 200 → 500，实体每请求仍最多 100 条、每轮最多并发 2 个请求。哈希校验、失败取消、命名空间隔离和完整覆盖提升均保留。23,553 项理论页数为 118 → 48；这是分页算术，尚不是部署后的实测。
6. **减少服务端读取和序列化。** devices 不再先取整套 syncStatus 后丢弃；read lease 根据调用方读取 metadata/settings 投影；无设备过滤的 full baseline 直接计数固定 cut 上的有效版本。增加 `0002_device_coverage_index.sql`，使设备覆盖 MIN/MAX 命中 partial covering index 的有序边界。

## 同条件本地复测

这些实验分别衡量不同组件，不能把百分比相加，或套用到上表的真实线上等待。

| 实验与指标 | 修改前 | 修改后 | 条件 |
| --- | ---: | ---: | --- |
| 门控数据全部返回 | 278.61 ms | 139.87 ms（−49.8%） | 真实 Workerd HTTP，me/compat 每次人为增加 120 ms，7 对 AB/BA |
| 浏览器热首页统计可见 | 490.4 ms | 385.7 ms（−21.4%） | 同一 Chrome，3 次热缓存中位，固定 120 ms 门控延迟；候选构建对照 |
| 首个可查询 read 就绪 | 464.50 ms | 186.25 ms（−59.9%） | 真实 controller/data source/transport，固定 80 ms dispatcher，1,000 实体，3 轮 |
| 完整缓存完成并核对内容 | 1,488.19 ms | 1,036.78 ms（−30.3%） | 同上；所有实体内容深度相等 |
| 6 个相同 usage / renew | 各 6 个请求 | 各 1 个请求 | 保留不同过滤器请求；不宣称单批查询延迟下降 |
| 过期凭证下 6 个查询成功数 | 0 / 6 | 6 / 6 | 1 renew、1 status、1 read 完成自动恢复，无 manifest 重扫 |
| 认证 devices HTTP | 209 ms | 7 ms | 本地真实 Workerd/D1，25k 事件、250 来源、2,500 回执，预热后 5 次中位 |
| syncStatus | 206 ms | 9 ms | 同上 |
| full createRead | 56 ms | 28 ms | 同上，无设备筛选 |

浏览器热首页计时取自最终删除竞态边界修复前的候选构建；最终构建另做下述功能验收，不移植早期计时。服务端六条路径各六轮完整规范化响应 SHA-256 与原版全部相同。manifest / entities / summary 的主要已证实收益是减少 D1 返回字段字节，summary 聚合扫描量仍为 150,012 读行，没有宣称其小幅时间变化是稳定加速。

索引独立 A/B：25k 候选、20k active，原双边界读取 50,001 行 / 196 ms → **3 行 / 3 ms**，EXPLAIN 两个子查询都命中 covering index。代价是该夹具数据库增加约 **2.06 MiB**，实际 200 / 500 事件写入总写行增加 **3.8% / 4.1%**；本地写入耗时没有观察到恶化，不能推断写入变快。索引迁移仅增加索引，不要求升级采集器协议，也不重建或清空数据库。线上收益需要先应用 0002。
