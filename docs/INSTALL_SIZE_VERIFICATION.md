# 安装依赖精简验收

2026-09-09，在 Windows x64、Node 26.7.0、npm 11.19.0 下，对同一版本 0.1.4 的调整前后安装包进行比较。

## 结果

| 指标 | 调整前 | 调整后 |
| --- | ---: | ---: |
| 安装包数（含项目自身及嵌套依赖） | 129 | 81 |
| 安装目录文件大小合计 | 100,971,913 B（96.29 MiB） | 26,369,260 B（25.15 MiB） |
| 安装目录文件数 | 15,627 | 4,115 |
| 项目 npm tarball | 565,255 B | 565,300 B |

安装目录文件大小减少 **73.9%**，超过本轮至少减少 50% 的目标。文件大小是逻辑字节数，不是磁盘分配空间、下载流量或运行内存。

tarball 不包含 npm 单独下载的依赖，所以其大小基本不变；本轮收益来自停止重复安装已经构建进网页的前端库。两个安装包的 `dist/` 文件集合及逐文件 SHA-256 完全一致。锁文件中的依赖版本、下载地址及 integrity 均未改变。

## 方法与复现

1. 在调整前后分别执行 `npm run build`，再执行 `npm pack --ignore-scripts --json --pack-destination <独立输出目录>`，记录实际 tarball 大小。
2. 使用相同 Node/npm，将各 tarball 用 `npm install -g --prefix <各自的仓库外临时目录> <tarball>` 安装。
3. 对各 prefix 的 `node_modules` 递归统计文件数及文件字节数；按各级 `node_modules/<包>` 和 `node_modules/@scope/<包>` 的包根目录统计包数，包含项目自身及嵌套依赖。
4. 比较两份安装包内 `dist/` 的逐文件 SHA-256，确认发布应用代码和资源不变。

全局 tarball 安装会解析依赖版本范围，未来 registry 状态或 npm 版本可能影响精确计数。安装耗时受缓存与网络影响，不作为验收指标。
