## 待办与验收

### SYNC-01：设计、实现及验收均纳入待办

- [ ] 定义首版单用户、单采集设备的云端只读统计快照；明确聚合粒度及远程可下钻范围。多设备合并需独立去重方案，首版不自动汇总不同电脑的同一会话。
- [ ] 制定字段白名单：时间桶、时区/UTC 边界、模型、Token 组成、质量标记、脱敏项目标识及必要 Agent 关系。项目路径和任务标题默认不上传；若允许别名或更细粒度信息，提供明确选择。
- [ ] 禁止上传原始 session、聊天/工具正文、登录凭据和实例控制 token；不把本地 SQLite 整库复制到云端。
- [ ] 定义版本化快照/增量契约、设备和数据集标识、幂等键、水位、重试退避与一致性校验；重解析可能修正旧统计，不能只按时间追加而无法纠错。
- [ ] Token 保持十进制字符串；保留 null、不完整记录、来源和账户身份状态。本地用量与账户额度分别同步，账户额度明确为历史快照。
- [ ] 选择云存储、认证和加密方式，记录费用边界、保留期、删除与撤销流程。区分传输/存储加密和端到端加密；若云端不能解密，需要定义客户端密钥恢复及查询限制。
- [ ] 实现本地出站同步、云端读取和移动查看，尽量复用现有展示契约；保持公开 showcase 仅使用合成 fixture。
- [ ] 展示最后采集时间、最后同步时间、设备状态和覆盖范围；禁止通过手机当前时间推断源数据已更新。
- [ ] 支持关闭同步、删除云端数据和断网后恢复；账户切换或重新绑定不得暴露旧身份快照。

#### 验收标准

重复上传不重复计数，离线重连不丢数据，修正旧数据可以收敛；电脑关闭后另一台设备仍能读取最后成功快照并识别其陈旧性；传输载荷和云端存储经合成数据检查符合白名单；撤销、隔离和删除有效。
