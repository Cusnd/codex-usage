## 待办与验收

### REMOTE-01：受认证远程查看

- [ ] 形成访问方案决策文档，比较私有网络和身份网关/隧道在手机接入、用户安装负担、成本、在线依赖与维护方面的差异；届时用供应商当前官方文档核查能力，选定一个首版路径。
- [ ] 先定义远程只读 API 白名单及身份边界，再实现适配。审计所有路由，包括服务管理、设置、刷新、启动管理、路径操作、文档与状态；不能只依靠隐藏按钮限制访问。
- [ ] 明确哪些 Host/Origin 被信任、代理身份如何验证以及如何防止伪造身份头或绕过网关。保持本地回环默认限制；不全局删除已有防护，不暴露 instance 控制 token。
- [ ] 远程默认展示统计；任务标题和项目路径的展示范围可控。云隧道可见哪些流量应如实说明，不能把“本地存储”描述为“流量不经过第三方”。
- [ ] 为远程模式定义能力响应，复用前端并隐藏不支持操作；首版自动更新依赖后端采集，远程手动触发刷新如需开放则另设限流契约。
- [ ] 给出单用户安装、设备访问、撤销访问、停用与故障排查步骤；电脑离线时显示不可连接，而非零消耗。

#### 验收标准

手机从外部网络经认证查看合成数据；未认证请求和伪造来源不能读取；远程不能调用本机管理接口；撤销访问生效；本地 CLI 和 Web 正常；原电脑离线行为符合说明。

## 待决策问题

首版采用私有网络还是身份网关/隧道；远程字段、刷新权限和 Agent 查询范围。
