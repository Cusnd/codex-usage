## 待办与验收

### UX-01：可视化与设计合理性

- [ ] 以现有 Overview、AtlasTrend、AtlasDirectory、AtlasSession、AgentUsage、Comparison 为基础审查信息顺序和交互，先记录具体障碍，再修改。
- [ ] 完整走通“发现某日峰值 → 小时/项目/模型 → 任务 → Agent → Turn”，检查筛选继承、返回路径、单位和计数口径。
- [ ] 检查对比页面是否能定位主要贡献项目或任务，并区分变化归因与原因解释。
- [ ] 审查缓存组成的分母说明、未知缓存写入、超大数值、空结果、加载失败和不完整记录的表达。
- [ ] 检查图表是否必须依赖 hover、颜色或拖拽才能读数；补充触控与键盘可完成的操作。
- [ ] 用合成数据记录修改前后的步骤、误读点和结果，不以新增图表数量作为成果。

#### 验收标准

三条核心场景（峰值定位、团队拆分、期间比较）均能完成；返回不丢上下文，图表和明细一致，错误与缺失不显示成零。
