- [ ] 验证弱网、断网、后台恢复、身份过期、刷新失败与重试；分别显示连接状态和数据新鲜度。
- [ ] 评估添加到主屏幕的价值后决定是否实现 PWA；不默认缓存认证响应和个人数据，离线历史优先由 SYNC-01 定义。

#### 验收标准

手机完成查看今日用量、检查额度、追踪高消耗任务三条路径；无页面级横向溢出，关键操作不依赖 hover；后台恢复后不会把旧快照显示为最新。
